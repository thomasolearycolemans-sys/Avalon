# Card scans go here

The app looks for files named exactly after each role's internal key, as a **.jpg**,
directly inside this folder (not in a subfolder). Add them whenever your scans are ready —
no code changes needed. A role with no file just keeps its blank placeholder in Help.

## Notes
- Lowercase, underscores exactly as shown, `.jpg` extension.
- If your scan is a `.png` or `.jpeg` instead, either rename it to `.jpg`,
  or ask for the one-line code change to accept that extension too.
- This file itself does nothing — delete it whenever you like, or leave it; the app ignores it.
